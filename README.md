# Kindle Highlights

简单的 Kindle 高亮解析网页工具，使用 Vue + Vite 构建。

快速开始：

安装依赖并启动开发服务器：

```bash
npm install
npm run dev
```

在浏览器打开 `http://localhost:5173`，上传或粘贴高亮文本进行解析。

主要文件：

- [index.html](index.html)
- [src/App.vue](src/App.vue)
- [src/parser.js](src/parser.js)
- [example/highlights.txt](example/highlights.txt)
